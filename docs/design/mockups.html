LifeLog · v1 screens

Early design drafts; docs/spec.md describes the current app. Gestures on the main list: long-press = multi-select delete · tap = detail sheet · the sheet has full-screen · edit · delete icons stacked bottom-right. Tap “LifeLog ›” for Settings; the trash is at the bottom of Settings. Data: one records table; content is never modified. Editing soft-deletes the old row and inserts a new row with the same entry_id and time, so old content simply sits in the trash.
